# 피클(써니)에게 — 네이버·쿠팡 분석 인계 요청

작성: Muse (2026-11-15) · 받는 쪽: 피클 써니
배경: 과일 공급가 DB 앱(Muse '실시간 소싱 비교 DB판')이 `fruit/data.json`을 매일 07:20에 동기화하고 있어요. 네이버 데이터랩 제철 분석과 쿠팡 분석은 써니가 맡기로 사용자가 정했습니다. 아래 형식으로 파일을 만들어 같은 레포 `fruit/` 폴더에 push해 주세요. 앱이 매일 아침 두 파일을 읽어 화면에 반영합니다.

## 공통 규칙
- 숫자를 못 구하면 빈 배열로 두고 `note`에 사유를 적어 주세요. 추정·가짜 숫자는 금지입니다.
- 품목 이름은 `fruit/data.json`의 카테고리·품목 표기와 똑같이 써 주세요 (매칭 기준).
- 파일마다 `updated_at`(KST)과 `source`(어디서 어떻게 구했는지)를 꼭 넣어 주세요.

## 1. 네이버 데이터랩 제철 지수 → `fruit/season.json`
- 대상: data.json의 과일 카테고리 27개 (사과·감·감귤·배·포도·복숭아·자두·살구·딸기·수박·참외·멜론·키위·망고·바나나·오렌지·레몬·자몽·라임·블루베리·체리·석류·대추·곶감·아보카도·용과·무화과), 가능하면 주요 품종(부사·샤인머스캣 등)도 추가.
- 방법: 데이터랩 검색어 트렌드 또는 쇼핑인사이트로 최근 12개월 '월별' 상대 지수(0~100)를 받아 주세요.
- 갱신: 매주 월요일 1회면 충분합니다.
- 형식:
```json
{
  "updated_at": "2026-11-17 08:00",
  "source": "네이버 데이터랩 쇼핑인사이트 월별 지수",
  "note": "",
  "items": [
    {
      "name": "감귤",
      "monthly": {"2024-12": 88.1, "2025-01": 61.2, "2025-11": 100.0},
      "this_month_index": 100.0,
      "vs_avg": 1.82,
      "vs_prev_month": 1.24
    }
  ]
}
```
- `vs_avg` = 이번 달 지수 ÷ 12개월 평균, `vs_prev_month` = 이번 달 ÷ 지난달. 계산이 어려우면 monthly만 줘도 앱에서 계산합니다.

## 2. 쿠팡 분석 → 비공개 전달(공개 레포에 올리지 않음)
- 쿠팡 파트너스 키·계정 정보가 담긴 파일은 공개 저장소(`gongmaemul-test`)에 올리지 않습니다. 분석 결과는 동곤 님께 직접 전달합니다.
- 쿠팡 '실시간 검색 순위'는 공식 API가 없다는 걸 알고 있습니다. 가능한 범위로 해 주세요: 쿠팡 파트너스 API 카테고리 베스트(과일) 또는 써니가 접근 가능한 베스트·인기 상품 목록.
- 상품명에서 우리 품목명이 포함되면 `matched_item`에 그 품목명을 넣어 주세요 (앱이 품목 카드에 '쿠팡 베스트 N위' 배지를 붙입니다).
- 갱신: 매일 07:10 data.json 갱신과 함께면 가장 좋습니다.
- 형식:
```json
{
  "updated_at": "2026-11-16 07:10",
  "source": "쿠팡 파트너스 카테고리 베스트",
  "note": "",
  "items": [
    {"rank": 1, "product_name": "상품명 전문", "matched_item": "샤인머스캣", "price": 15900, "url": "https://..."}
  ]
}
```
